# tw-duty-roster｜自動值班排班表

給台灣的**房仲門市、小店、診所櫃台、社團**用的值班排班表。打開網頁、勾一勾規則、按一下就排好整個月，可以列印或匯出 Excel。

- **免安裝、免伺服器**：一個資料夾，雙擊 `index.html` 就能用，沒有網路也能用。
- **資料不外流**：人員、請假、班表只存在你這台電腦的瀏覽器裡，不會上傳到任何地方。
- **規則可以調**：誰哪幾天能值班、誰固定哪天、每週最多幾次、請假、每天幾個人。
- **排完會自動檢查**：缺人、請假還被排到、超過每週上限、連續兩天值班，都會列出來。

---

## 適合誰

| 情境 | 用哪個範本 |
|---|---|
| 門市每天要有 1 個人留守（例如房仲店的值班、櫃台輪值） | **門市每日值班** |
| 只有週末要排人，平日不用（例如週五六固定一人、週日兩人輪流） | **週末三人輪班** |
| 其他情況 | 選一個最像的範本，再在網頁上改人員和規則 |

## 5 分鐘開始

1. 下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮。
2. 雙擊 **`index.html`**，用 Chrome、Edge 或 Safari 打開。
3. 依序設定：
   1. **期間與範本**：選月份（預設是下個月），或自訂起訖日期。
   2. **人員**：改名字、勾可以值班的星期、固定值班的星期、每週上限。
   3. **規則**：哪幾天要排人、每天幾人。
   4. **請假**：按「新增請假」，選人和日期。
4. 按右上角 **產生排班**。
5. 想手動調整就**點格子**：點一下加上值班，再點一下拿掉。改完下方會重新檢查。
6. 按 **列印／存 PDF**（建議 A4 橫向），或 **匯出 Excel（CSV）**。

> 網頁上改的設定會自動記在這台電腦的瀏覽器裡，下次打開還在。
> 換電腦或清除瀏覽器資料後會回到預設範本。

## 排班規則怎麼運作

每一天依序：

1. **固定班優先**：這個星期有人設定「固定值班」，就排他。他當天請假的話，改用下一步找人。
2. **找可以排的人**：當天可值班、沒請假、這週還沒到上限、昨天沒值班（有勾「盡量不要連續兩天」時）。
   如果明天是某人的固定班，今天就先不排他，避免連兩天。
3. **誰值得最少誰先**：整段期間值班次數最少的人先排；一樣多就排最久沒值班的；再一樣就照名單順序。
4. **排不出人時**：有勾「放寬每週上限」就讓還沒勾「嚴格」的人多排一次；還是排不出來就留空，並在下方提醒「缺人」。

同樣的設定每次排出來都一樣（不靠亂數），方便大家對照。

## 改預設範本（給會用記事本的人）

網頁上能改的東西都可以直接在網頁改。想改「預設範本」（例如發給分店用），打開 **`config.js`**：

```js
window.ROSTER_CONFIG = {
  title: '示範不動產 值班表',   // 網頁和列印的標題
  noteLabel: '店長的話',          // 表格下方備註欄的名稱
  defaultPreset: 'daily',
  presets: {
    daily: {
      label: '門市每日值班',
      rules: { dutyDays: [0,1,2,3,4,5,6], slotsPerDay: 1, weekStartsOn: 1, avoidConsecutive: true, relaxWhenShort: true },
      staff: [
        { id: 'manager', name: '店長', color: '#2563eb', days: [0,1,2,3,4,5,6], fixedDays: [0], maxPerWeek: 2 },
        // …
      ],
    },
  },
};
```

星期代號：`0`＝日、`1`＝一 …… `6`＝六。各欄位說明寫在 `config.js` 檔案最上面。
改完存檔，在網頁上選範本，按「套用範本」。

## 給開發者

```
index.html        畫面
css/style.css     樣式（含列印、深色模式）
config.js         範本設定
js/scheduler.js   排班引擎：純函式，瀏覽器和 Node 都能用
js/app.js         畫面邏輯、存到 localStorage
tests/            單元測試（node:test，不用裝任何套件）
```

跑測試（需要 Node.js 18 以上）：

```bash
npm test
```

`scheduler.js` 主要函式：

| 函式 | 用途 |
|---|---|
| `generate({start, end, staff, rules, leaves, locked})` | 自動排班，回傳 `{plan, warnings, counts}` |
| `check({start, end, staff, rules, leaves, plan})` | 檢查任何一份班表（手動改過的也行） |
| `toCSV({start, end, staff, leaves, plan})` | 匯出 CSV（含 BOM，Excel 直接開不亂碼） |

---

## 注意事項

- 這是「值班安排」工具，不計算工時和薪資。原則上，排班若涉及加班、休息日、例假，仍請依《勞動基準法》與勞動部最新公告自行確認。
- 資料存在瀏覽器的 localStorage，無痕視窗關掉就會消失；重要的班表請列印或匯出留存。
